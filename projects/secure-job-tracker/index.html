Privacy notes

Data is stored in localStorage in this browser profile. Anyone with access to this browser profile may be able to view it. Avoid storing passwords, ID numbers, or other highly sensitive information. Exported CSV files contain the records you choose to export.

This is a frontend MVP, not a multi-user service. Authentication, server-side storage, and encryption-at-rest are not implemented.
