Security notes

  • Each account should only see its own applications, enforced by PostgreSQL row-level security.
  • Use a Supabase publishable key only; a publishable key is not a substitute for RLS.
  • CSV export is hardened against common spreadsheet formula injection.
  • Read the setup guide and security limitations before configuring a live project.
