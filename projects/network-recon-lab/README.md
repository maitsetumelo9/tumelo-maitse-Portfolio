# Network Recon Lab

An offline, browser-based learning lab for interpreting illustrative Nmap-style results and reviewing common TCP ports.

## Features
- Three fictional sample scenarios: web server, Linux practice host, and filtered services.
- Port lookup with analyst-oriented notes.
- Authorisation and reporting checklist.
- Responsive layout with keyboard focus indicators.

## Run
Open [index.html](index.html) in a modern browser. No package installation or network requests are required.

## Safety and limitations
This project **does not perform scans** or send packets. All scan output is synthetic, and addresses use the documentation-only `192.0.2.0/24` range. Port numbers alone do not prove a vulnerability. Only test systems for which you have explicit permission.

## Skills demonstrated
HTML, CSS, JavaScript, event handling, data-driven UI, input validation, and safe security documentation.
