Hash & Encoding Lab

Explore the difference between reversible encoding and one-way hashing. All operations run locally in your browser; input is not uploaded or saved.

Input

Do not paste passwords, API keys, personal information, or other secrets into a learning demo.

1. Base64 encoding and decoding

Base64 changes representation; it does not encrypt or protect data. Anyone can decode it.

2. SHA-256 hashing

A cryptographic hash produces a fixed-length digest. Hashing is not encryption and cannot be reversed to recover the original text.

Security notes

Base64: encoding, not confidentiality. SHA-256: a general-purpose hash, not a password-storage scheme by itself. Real password storage should use a purpose-built password hashing function such as Argon2id, scrypt, or bcrypt with appropriate parameters and salts.
